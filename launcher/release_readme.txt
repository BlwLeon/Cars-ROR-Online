Race-O-Rama Online
==================
Online multiplayer for Cars Race-O-Rama (Nintendo DS, Europe)
Online-Mehrspieler für Cars Race-O-Rama (Nintendo DS, Europa)
https://github.com/BlwLeon/Cars-ROR-Online

EN
--
1. Start "RORM Online.exe". If Windows shows "Windows protected your PC",
   click "More info" -> "Run anyway" (the program is not code-signed yet).
2. Choose your language and select your own copy of the game (.nds, Europe).
3. Server tab: search and select a server, or start your own.
4. Play tab: "Host a room" or "Join a room".
To play with friends, everyone needs Tailscale (tailscale.com, free) in the
same tailnet. Full guide: see the GitHub page.

DE
--
1. "RORM Online.exe" starten. Zeigt Windows "Der Computer wurde durch Windows
   geschützt": "Weitere Informationen" -> "Trotzdem ausführen" (das Programm ist
   noch nicht signiert).
2. Sprache wählen und die eigene Kopie des Spiels auswählen (.nds, Europa).
3. Reiter Server: Server suchen und auswählen oder selbst einen starten.
4. Reiter Spielen: "Raum hosten" oder "Raum beitreten".
Zum Spielen mit Freunden brauchen alle Tailscale (tailscale.com, kostenlos) im
selben Tailnet. Ausführliche Anleitung: siehe GitHub-Seite.

Folders / Ordner
----------------
RORM Online.exe   launcher
server\           server (RORM-Server.exe)
melonDS\          bundled melonDS (GPL-3.0, unmodified official build,
                  source: https://github.com/melonDS-emu/melonDS)
mod\net.elf       online patch
user\             your data: online ROM, save file, settings (created on first start)
