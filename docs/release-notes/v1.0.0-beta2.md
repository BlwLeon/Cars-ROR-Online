Second beta of **Race-O-Rama Online** – thanks for all the feedback on beta 1!

### Download
**`RORM-Online-1.0.0-beta2-windows.zip`** below → unzip → start `RORM Online.exe`.
You need your own copy of the game (`.nds`, Europe / `B6OP`). No game files are included.
Updating from beta 1: unzip into a new folder and copy your `user` folder over (keeps ROM setup, settings and save).
**Everyone in a room needs beta 2** (mod R11) – host the server with beta 2 as well.

> Windows may show *"Windows protected your PC"* because the program is not code-signed yet:
> *More info → Run anyway*.

### What's new
- **Frame-exact race start, even with emulator lag.** All players now share the game's sync clock. If one
  emulator stutters after the sync (shader compiling, loading), the others wait for it instead of starting early.
- **Server search beyond Tailscale.** The launcher now also searches every local network adapter by broadcast –
  LAN, **Radmin VPN**, ZeroTier, Hamachi. The same server is listed only once, and the host sees all of
  their LAN/VPN addresses. *(Not tested with other people yet – please report how it works for you.)*
- **Working profile stats.** The server records every race and the launcher fetches it:
  races, wins, **average place**, most frequent rivals and the correct driver names for host and clients.
- **Race details.** Click a race in *Recent races* to see every driver with finish time, best lap and all lap
  times. Players timed out by the game are shown as *DNF*.
- **Track & laps** are recorded per race. Track names are not mapped yet (shown as *Track 3*) – we are collecting
  the list; the server window shows the track number when the host picks a track.

### Fixes
- Sporadic launcher crashes at startup: controller detection now starts only when the settings page is opened,
  and each install uses its own WebView2 data folder (two launchers at once work too).
- If the launcher still crashes, details are written to `user\crash_log.txt` – please attach it to an issue.

### Known limitations
- Track names are not shown yet.
- Radmin/VPN networks: Windows often marks the Radmin adapter as a *public* network – the host must allow the
  server in the firewall for public networks too. If a server is not found, enter the host's VPN IP manually.

See the [README](https://github.com/BlwLeon/Cars-ROR-Online#readme) for the full guide.
