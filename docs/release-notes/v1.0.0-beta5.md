Fifth beta of **Race-O-Rama Online** – fixes the two problems from the beta 4 session.

### Download
**`RORM-Online-1.0.0-beta5-windows.zip`** below → unzip → start `RORM Online.exe`.
You need your own copy of the game (`.nds`, Europe / `B6OP`). No game files are included.
Updating: unzip into a new folder and copy your `user` folder over (keeps settings, save and race history).
**Everyone in a room needs beta 5** (mod R14) – including whoever runs the server.

> Windows may show *"Windows protected your PC"* because the program is not code-signed yet:
> *More info → Run anyway*.

### Fixes
- **Frame-exact start from the 2nd race on.** Beta 4 only synchronised the start of the *first* race in a lobby:
  the game keeps its race-data exchange running between races, so from race 2 on every start counted as
  "mid-race" and the sync was skipped – the host could start early and it took 5–10 s until all cars matched.
  Every race start is synchronised again now.
- **Slow-loading players are waited for.** Before the start, consoles now wait up to ~10 s (was 2 s) for a
  player whose emulator is still loading (shader compiling etc.) instead of starting without them.
- **Timed-out players on 1-lap tracks are ranked last.** The game sends a random substitute time for players
  who did not finish on point-to-point tracks (often faster than the winner). The server now replaces it with
  99:59.99, so the in-game result screen ranks them last. On multi-lap tracks the game's own projected times
  are kept (they are fair) and used for the result and the profile stats.
  *(The timed-out player may still see the wrong time on their own screen – that one is computed locally.)*

What beta 4 already fixed (growing offsets / freezing with a Wi-Fi player) is unchanged.

See the [README](https://github.com/BlwLeon/Cars-ROR-Online#readme) for the full guide.
