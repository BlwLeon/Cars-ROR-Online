Third beta of **Race-O-Rama Online** – mostly stability fixes from the 4-player sessions with beta 2.

### Download
**`RORM-Online-1.0.0-beta3-windows.zip`** below → unzip → start `RORM Online.exe`.
You need your own copy of the game (`.nds`, Europe / `B6OP`). No game files are included.
Updating: unzip into a new folder and copy your `user` folder over (keeps settings, save and race history).
**Everyone in a room needs beta 3** (mod R12) – including whoever runs the server.

> Windows may show *"Windows protected your PC"* because the program is not code-signed yet:
> *More info → Run anyway*.

### Fixes
- **4-player lobbies no longer get stuck.** With 4 players (and especially with high ping) game messages could
  be lost – the host could start while everyone else waited forever, positions froze, and only a server restart
  helped. Messages are now never dropped, and oversized race-data packets are no longer silently skipped.
- **Frame-exact race start with high ping again.** The start sync mixed up the game's 30 fps with the 60 Hz sync
  clock, so with ~200 ms ping the start drifted by several frames and consoles paused their clock unnecessarily.
- **Server never freezes from a click.** Clicking into the server window used to pause the whole server
  (Windows text selection). This is now switched off.
- **Server safety net:** a connection that stops acknowledging messages is reset automatically after 20 s
  instead of blocking the room; broken packets can no longer stop the server.
- **Launcher "not responding" at startup:** the launcher no longer creates a fresh WebView2 profile on every start
  (the step where it sometimes hung for 20–35 s). If it still hangs, `user\crash_log.txt` now records why.
- If your original game file was moved or deleted after an update, the launcher now asks for it instead of
  silently playing with an outdated patch (which would desync with others).
- Keyboard: Y/Z and Ä/Ö/Ü are recognised correctly on German keyboards.

### New
- **Track names** in the race history, including the variant (e.g. *Radiator Springs 2 · 3 laps*).
- Rivals are grouped by online ID – renaming no longer creates a second entry.
- Aborted races (nobody finished) are no longer counted.
- The server keeps the logs of the last 5 sessions (`server_log.1.txt` …) and shows the track number in its window.
