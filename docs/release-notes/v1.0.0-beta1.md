First public beta of **Race-O-Rama Online** – online multiplayer for *Cars Race-O-Rama* (Nintendo DS, Europe).

### Download
**`RORM-Online-1.0.0-beta1-windows.zip`** below → unzip → start `RORM Online.exe`.
You need your own copy of the game (`.nds`, Europe / `B6OP`). No game files are included.

> Windows may show *"Windows protected your PC"* because the program is not code-signed yet:
> *More info → Run anyway*.

### Highlights
- Online races for up to 4 players (incl. Grand Prix) with custom netcode
- *Host a room* / *Join a room* – the game jumps straight into the lobby
- Automatic server search in your Tailscale network, one-click hosting
- Separate online profile with all cars and tracks unlocked
- Keyboard & controller mapping with in-game action names, display/upscaling settings
- English & German, bundled melonDS 1.1

### Networking
Currently for groups of friends via **Tailscale** (or a public IP with port forwarding).
Ideas for public servers or want to host a community server? Please open an issue.

See the [README](https://github.com/BlwLeon/Cars-ROR-Online#readme) for the full guide.
