Fourth beta of **Race-O-Rama Online** – fixes for the position offsets and desyncs with players on Wi-Fi /
far away, found in the beta 3 sessions and reproduced locally with a simulated Wi-Fi connection.

### Download
**`RORM-Online-1.0.0-beta4-windows.zip`** below → unzip → start `RORM Online.exe`.
You need your own copy of the game (`.nds`, Europe / `B6OP`). No game files are included.
Updating: unzip into a new folder and copy your `user` folder over (keeps settings, save and race history).
**Everyone in a room needs beta 4** (mod R13) – including whoever runs the server.

> Windows may show *"Windows protected your PC"* because the program is not code-signed yet:
> *More info → Run anyway*.

### Fixes
- **No more growing position offset / freeze with a Wi-Fi player.** A single Wi-Fi dropout made the race delay
  jump to its maximum; at that size the race-data buffer overflowed and the consoles waited for data that had
  already been overwritten – other cars lagged several seconds behind until everything froze.
  The buffer is twice as large now, the delay is capped lower, ping spikes are smoothed out and the delay
  shrinks again once the connection is calm.
- **The sync clock is no longer paused during the race** (only before the start), which also caused offsets.
- **Race start in sync again for the host** (beta 3 tests).
- **Launcher "not responding" at startup:** found the cause – pywebview inspected the window object and got stuck
  in WebView2 internals. Fixed.
- **Timed-out players are no longer ranked as winners.** The game ends a race ~10 s after the first finisher and
  sends a substitute time for everyone else (on 1-lap tracks it can even be faster than the winner). Only players
  who finished within that window count; everyone else is shown as *DNF*.

### Other
- Graphics settings: new option *OpenGL compute shader*, and a hint that melonDS' OpenGL renderer sometimes shows
  a black screen in this game (also offline) – switch to *Software* if it happens.
- Server window: real ping in ms, plus per player the race delay (D), waiting frames and game fps – this makes
  bug reports much easier. `--spike` simulates Wi-Fi dropouts for testing.

See the [README](https://github.com/BlwLeon/Cars-ROR-Online#readme) for the full guide.
